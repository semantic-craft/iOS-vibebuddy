# VibeBuddy Mac 1.3.44

Antigravity CLI and desktop tasks now appear automatically, with their source shown on each session. VibeBuddy distinguishes questions, permission waits, completed results, cancellations and observation problems. Handle requests in Antigravity itself; this integration is read-only.

Account usage now shows Antigravity’s independent model groups, allowance windows and reset times from the signed-in CLI account. Compact readings name the limiting model group. Desktop account identity is not assumed to match the CLI.

The Mac reader uses native full transcripts. VibeBuddy iPhone 1.3.35 and Watch show the same source labels, waiting reasons and quota groups; iPhone can read complete Antigravity results up to 128 Ki characters, with an explicit unavailable result beyond the supported limit.

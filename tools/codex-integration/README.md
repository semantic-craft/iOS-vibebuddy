# Codex integration checks

Run from the repository root after a Codex upgrade:

```sh
python3 tools/codex-integration/probe.py audit
```

This checks installed/managed/running daemon versions, live hook trust, all literal
client methods used by the monitor, and critical required fields against schemas
generated by the installed CLI. It does not mutate configuration or trust hooks.
Compare the version separately with the [official changelog](https://learn.chatgpt.com/docs/changelog).
A passing audit is not delivery or device acceptance.

For a task created by the user in Desktop, start the probe before triggering an
approval (copy the task ID from its menu):

```sh
python3 tools/codex-integration/probe.py watch --thread UUID --seconds 600 > evidence.jsonl
```

The probe subscribes only to that task, tails only its new rollout records, and
reads its VibeBuddy snapshot on localhost:9876 using the configured token without
logging the token. Only metadata is printed. It never starts turns or responds to
approvals. If Desktop owns another app-server writer, subscription is unavailable;
the probe records this and continues with rollout and snapshot evidence. Do not
interpret missing socket events as proof that Desktop emitted none.

Acceptance: check native waiting state against the exact task's hook evidence,
rollout events and pending card. Have the user approve/deny and verify that the
same request resolves and the card clears. A hook lifecycle event is not proof of
a PermissionRequest, and a daemon's version is not proof it owns Desktop tasks.

An explicit real-daemon test uses the configured account, a disposable thread (archived on success),
and no shell/file/network action. It enables `features.request_permissions_tool`
only in that disposable thread (the feature is off by default in 0.153.4). It requests a network permission profile only,
rejects a persistent choice and approves the turn-scoped request via the actual
VibeBuddy HTTP route handler:

```sh
VIBEBUDDY_CODEX_LIVE_ACCEPTANCE=1 swift test --package-path VibeBuddyMac --filter CodexLivePermissionsTests
```

This tests a daemon-owned task; it does not test Desktop-private IPC or the phone.
The test is disabled in ordinary test runs.

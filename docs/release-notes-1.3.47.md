# VibeBuddy 1.3.47

- Keep connected agents, including Cursor, visible even when they have no current sessions.
- Show zero for idle agents while keeping older tasks separate from current-session counts.
- Receive Grok Bot result notifications automatically and preserve unread records across restarts, with bounded offline recovery.

## 中文

- 已接入的代理常驻显示，Cursor 不再因为没有当前会话而从代理栏消失。
- 没有当前会话时显示 0；较早任务仍单独展示，不增加当前会话数量。
- 自动接收 Grok Bot 结果通知，未读记录跨重启保留，并补回有限的离线通知。

# VibeBuddy iOS 1.3.37

## English

Choose Japanese as the reading language to request Japanese task summaries from an updated paired Mac. Gemini, Qwen, Doubao and MiniMax offer compatible Japanese voices. Voice previews now use the selected reading language.

## 简体中文

新增日语朗读语言，可向更新后的配对 Mac 请求日文任务摘要。Gemini、Qwen、豆包和 MiniMax 均提供兼容的日语播报音色，试听内容跟随所选朗读语言。

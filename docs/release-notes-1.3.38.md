# VibeBuddy 1.3.38 — macOS

## 简体中文

- 刘海浮层优先显示在 MacBook 的内置刘海屏，严格保持实体刘海宽度；合盖后切换为外接屏胶囊，开盖后自动恢复。内置刘海默认使用更协调的小号字体，仍可手动调整。
- 连接中心可以明确选择「同一 Wi-Fi」或「在外连接」。同一 Wi-Fi 的局域网连接也支持安全发送到 iPhone，手机检查成功后再保存。
- 修复窄刘海中较长语音状态文字的截断。
- 朗读项目名称时使用项目名称，避免读出工作树目录的随机标识。
- 更新 macOS 发布签名，支持从现有版本迁移到新的更新签名密钥。

Mac build 56。配套 iPhone / Apple Watch 版本为 1.3.31（64）。

## English

- Glance prefers the MacBook's built-in notch display and stays within the physical notch width. Closing the lid moves it to a capsule on an external display; reopening restores it to the notch. The notch now defaults to the smaller text preset, with manual size controls preserved.
- Choose Same Wi-Fi or Away from Mac explicitly in the connection center. Local-network connections can also be sent securely to iPhone and are saved only after the phone checks them successfully.
- Longer voice status labels wrap inside the narrow notch.
- Spoken project names use the project name instead of random worktree directory identifiers.
- Refreshed macOS signing and the update signing key with compatibility verification against the previous release.

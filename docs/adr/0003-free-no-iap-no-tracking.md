# Free, no IAP, no analytics, no tracking

The iOS app ships free with no in-app purchase, no StoreKit, no analytics SDK,
and no tracking. This sidesteps the App Store payment-review minefield and
reduces the review surface to "no private API + accurate privacy +
experienceable." The main residual risk is Guideline 4.2 (companion app the
reviewer can't fully verify without the user's Mac), mitigated by a built-in
**Demo Mode** and the app's own interactive value (voice companion + remote
approve/answer) so it isn't merely a Mac mirror.

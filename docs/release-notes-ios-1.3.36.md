# VibeBuddy iOS 1.3.36

## English

Gemini is now available for reading task results aloud and realtime voice conversations. Paired Macs can also generate Gemini completion summaries. Choose providers independently, use your own API key, and adjust the voice and speaking style. Long readings now preserve every audio segment.

## 简体中文

新增 Gemini 任务结果朗读和实时语音通话，配对的 Mac 也可生成 Gemini 完成摘要。各项用途可独立选择服务，使用自己的 API Key，并调整声音与播报风格。长文本朗读会完整保留各段音频。

# VibeBuddy 1.3.19 — macOS

- 刘海状态现在显示在摄像头左右，收起高度与真实刘海一致，移除下方多出的黑条。
- 两侧宽度根据图标和文字自动调整，减少空白；摄像头区域保持对齐，尺寸直接读取当前屏幕，无需按 Mac 型号配置。
- 保留展开、事件提醒和无刘海屏幕的显示方式。

## English

- Compact status now appears beside the camera housing at its actual height, removing the extra black strip below it.
- Side widths adapt to icons and text with less empty space. The camera gap stays aligned using the current display geometry, with no model-specific configuration.
- Expanded content, event cards and notchless displays retain their existing behavior.

Mac build 31. iPhone and Watch TestFlight build 46 are unchanged.

# VibeBuddy 1.3.25 for iPhone and Apple Watch

## 简体中文

- 收件箱标题下新增代理条：横向列出 All 与每个代理，显示品牌标、额度环、待办红点和会话数。选中一个代理后，心情行、First up、四块 tile、项目列表以及打开的列表页、朗读队列和新建任务都只针对它；代理条本身始终统计全部代理，别的代理卡住时仍能看到。
- Customize 表单不再包含代理选择器，重置也不会清除代理条的选择。
- Apple Watch 的额度条带上代理的品牌标与简称，按各自显示的剩余百分比从低到高排序；剩余 10% 及以下时，待批准卡片和任务详情会在身份行标出剩余额度。
- 修正诊断行颜色测试与 Companion 令牌不一致的问题。

## English

- An agent strip under the Inbox title lists All and each agent with its brand mark, allowance ring, needs-you dot and session count. Selecting an agent scopes the mood line, First up, the four tiles, the project list, the list pages opened from tiles, the read-aloud queue and New task to that agent; the strip itself always counts every agent, so a stuck agent stays visible.
- The Customize form no longer has an agent picker, and Reset no longer clears the strip's selection.
- On Apple Watch, allowance bars carry each agent's brand mark and short name and sort by the remaining share they show, lowest first. At 10% remaining or below, approval cards and task details note the remaining allowance on the identity line.
- Diagnostic-row colour tests now match the Companion palette tokens.

iOS build 55. The accompanying Mac release is 1.3.27 (45).

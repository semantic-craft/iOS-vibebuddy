# VibeBuddy iOS 1.3.38

## English

Connected agents, including Cursor, remain visible in the agent strip even when they have no current sessions. Idle agents display zero, and older tasks stay separate from current-session counts. Use VibeBuddy Mac 1.3.47 or later for the matching Mac dashboard update.

## 简体中文

已接入的代理常驻显示，Cursor 不再因为没有当前会话而从代理条消失。没有当前会话时显示 0，较早任务仍单独展示，不增加当前会话数量。请配合 VibeBuddy Mac 1.3.47 或更新版本使用。

# VibeBuddy 1.3.24 for iPhone and Apple Watch

## 简体中文

- 可在 iPhone 上新建由 Mac 端管理的 Grok 任务、继续对话、回答问题、处理支持的批准请求和停止任务。运行期间发送的补充指令会排队到下一轮。

- 首次打开时，用两步清单引导安装 Mac 端和扫码配对。可分享或复制 Mac 下载链接，也可跳过已完成的安装步骤。
- 灵动岛恢复显示主要状态的任务数量，超过 99 时显示 99+。
- 完成摘要优先说明下一步可执行的操作，方便接着处理任务。

## English

- Start Mac-managed Grok tasks from your iPhone, continue conversations, answer questions, handle supported approvals, and stop tasks. Instructions sent while a task is running wait for its next turn.

- Get started with a two-step checklist for installing the Mac app and scanning to pair. Share or copy the Mac download link, or skip installation if you have already completed it.
- Restore the task count for the primary state in the Dynamic Island, showing 99+ for larger counts.
- See the next actionable step first in completion summaries.

Status: ready-for-agent

**What to build:** 手机朗读配置与明确保存，作为本期 iOS 与 macOS 配套工作的完整用户路径。

**Blocked by:** None (can start immediately).

- [ ] MiniMax 在手机可选；清楚区分 Mac 摘要生成、本机朗读、两端独立凭据。
- [ ] 密钥编辑先留草稿，明确保存/取消/删除；取消读取或保存失败不覆盖已有可用配置，不回显秘密。
- [ ] 朗读语言可在当前页面调整，并与实时对话语言分开；未设置时保留原语言行为。
- [ ] 非标准风格显示实际音色和模型；标准风格保留用户配置；中英文文案可读。

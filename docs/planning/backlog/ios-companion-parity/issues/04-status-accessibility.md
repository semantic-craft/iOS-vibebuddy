# 04: 手机状态、语言与无障碍

Status: ready-for-agent

**What to build:** 手机状态、语言与无障碍，作为本期 iOS 与 macOS 配套工作的完整用户路径。

**Blocked by:** None (can start immediately).

- [ ] 区分 working、观测中断、historyOnly，操作遵从现有 ControlChannel/ActionSupport，保留原有轮次和草稿约束。
- [ ] 观测诊断能说明已配置与正在接收不同，提供在 Mac 处理的准确指引，不虚构能力。
- [ ] 新状态及控件有准确 VoiceOver label/value/hint；大字号可达、状态不只靠颜色，不抢焦点。
- [ ] 核对 iOS 中文和界面语言行为，采用系统原生语言入口而不照搬 Mac 退出重启。

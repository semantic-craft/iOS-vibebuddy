# iOS companion parity — 2026-10-02

用户授权将第一批和第二批全部拆票，并用 implement 技能、多子代理完成实施和验证。
基线：macOS 1.3.40，commit 3b6f481f。AX 同时覆盖代理能力表达与无障碍。

用户结果：手机能可靠配置和播放 MiniMax 摘要，理解 Mac/手机配置归属；只读查看 Codex 目标、分页历史及后台终端；准确区分观测、控制和过期状态。新旧 Mac 都有清晰降级。

延续 ADR-0002 的设备直连 TTS 与本地密钥；ADR-0024 的读取不改变生命周期/确认状态；保留 sourceID、sessionID、completionID/revision 和不透明分页游标。无声换服务、隐式接管终端、暴露新写权限不在范围。不得为配套功能建新云服务。

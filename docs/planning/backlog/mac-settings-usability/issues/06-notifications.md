# SET-06：本机通知规则清楚且设置可操作

Status: ready-for-agent
Blocked by: None（可立即开始）
Parent: [SET-01](01-settings-ux-dx-ax.md)

## What to build

用户能看懂系统授权与通知偏好的区别，并准确配置静音及类别。

## Acceptance criteria

- [ ] 系统拒绝通知时突出阻止状态并保留系统设置入口，不把偏好on当作通知可用。
- [ ] 审批/提问静默保留、其他会话提醒抑制及额度例外放在相关控件旁，减少重复段落。
- [ ] 全部开关有明确AX名称、稳定ID和当前值，禁用状态有原因；中英文、键盘与最小窗口可用。
- [ ] 现有通知规则、默认值、偏好键不变；隔离验证设置与相应表现，不修改生产系统权限。

## Boundaries

保留既有未提交工作；不变更真实凭据、生产安装、连接协议或既有默认行为。每票包含适用构建、Computer Use 和回归验证，记录已验证与未验证状态。所有UI修改同时评估UX、DX、AX，优先复用现有组件，不引入设置框架。

## 问题清单与验收

### P1：操作容易误解或无法稳定定位

- [ ] **S01 控件缺少名称与对象（实测＋源码）。** General 的开机启动、菜单栏、Glance，以及 Notifications、Usage sources 等开关只暴露 `toggle button on/off`。三个快捷键按钮均叫 Record，四个服务商按钮均叫 Add key，诊断中多个按钮均叫 Repair。Voice 的 Content style 同时暴露两个相同 ID 的菜单节点。
  - 方案：空标题 Toggle 改为真实语义标签并保持视觉标签隐藏；按钮加目标对象、稳定 ID；复核 MenuPill 的重复节点，保证一个明确的可操作入口。不要合并整页 AX 节点来隐藏控件。
  - 验收：不依赖坐标或前一条文本即可区分每个开关、快捷键、服务商与修复动作；读出当前值、禁用状态和原因。更换界面语言后 ID 稳定。
- [ ] **S02 密钥编辑即时覆盖，Done 只收起（实测＋源码）。** Qwen 编辑区没有 Save/Cancel；`keyInput` 每次变化调用 `SettingsCredential.edit`，后者立即执行 `KeychainStore.set`。本轮未用真实凭据复现覆盖。
  - 方案：密钥用临时草稿，明确 Save/Cancel；保存失败保留草稿和旧已保存值，并提供重试；移除密钥是独立动作，不能由清空输入隐式触发。保存与“连接已验证”分开呈现。
  - 验收：编辑、取消、切页或关闭窗口都不偷偷覆盖旧值；保存成功才更新已保存状态；测试只使用明确的已保存配置；不在日志或工单记录密钥。既有 Keychain account 名不变。
- [ ] **S03 语音配置缺少可执行的顺序（实测）。** Voice 一次展示通话、摘要、朗读、model ID、音色及共享语言；缺密钥时仍展示完整表单，朗读显示 Waiting for a summary provider。缺密钥链接实际跳转 Provider keys，AX 提示却说 “account below”。
  - 方案：每个功能展示“未开启／缺配置／可测试／已验证／失败”的准确状态和下一步；保留三项独立功能。加密钥后提供返回原功能的入口；高级 model ID 保留但折叠，显示实际默认值。修正错误跳转说明。
  - 验收：从无密钥到完成配置能沿可见动作走通，不需猜跨页依赖；缺配置时不声称功能可用；取消配置不自动开启功能；不改变现有默认模型和朗读依赖规则。
- [ ] **S04 “Connect”用途不明（实测）。** 同一组还有 Devices & connection 和 Agent CLIs；进入 Connect 后才知道是给 Agent 配 MCP。
  - 方案：改为“Agent 工具（MCP）”等明确名称，说明读取交接事实和会话；保留现有页面身份及跳转。CLI 页面用“接入编程助手”及动作说明，原理术语放次级说明。
  - 验收：侧栏即可区分手机连接、Agent 监控接入、MCP 读取；同步更新入门文档中的路径，不改变命令和 MCP 契约。
- [ ] **S05 手机通知折叠区混入监控故障（实测＋源码）。** Devices & connection → Notifications & delivery 展开后主要列 Claude/Codex/Grok/Cursor 的 Hook/App server 状态。
  - 方案：手机页只呈现与手机连接和投递有关的状态及诊断入口；Agent 监控问题放在 Agent CLIs/Diagnostics。继续区分配对已保存、收到地址、检查成功、通知服务接受、设备实际显示。
  - 验收：寻找手机通知问题不会先遇到无关 hook 列表；投递失败仍可见，诊断信息无丢失；遵守 ADR-0025。

### P2：降低理解成本，保持现有行为

- [ ] **S06 通知规则靠长段落记忆（实测）。** Show notifications 为 on，但 macOS 权限 Denied；已有权限解释和系统设置按钮，应保留。Quiet 的例外在两段长说明里重复；额度提醒绕过 Quiet 的规则容易漏看。
  - 方案：顶部显示“本机通知被系统阻止”和现有修复入口；把静音效果与额度例外放到对应控件旁，减少重复段落。清楚区分用户偏好和系统授权。
  - 验收：不把偏好 on 显示成“通知正常”；准确说明审批/提问静默保留、其他会话提醒抑制、已开启额度提醒的例外；不修改投递决策及默认值。
- [ ] **S07 Usage sources 承载超出“用量”的能力（实测）。** 页尾 Cursor cloud agents 密钥说明包括继续和取消任务，却藏在用量来源下面；总说明又把多种账户读取方式挤在一段话中。
  - 方案：将 Cursor cloud agents 配置入口放到 Agent 接入页；用量页按来源显示状态和对应说明，保留已有登录来源选项。
  - 验收：用户在 Agent 接入中能找到云端任务配置；用量来源开关不会被误认为关闭会话监控；复用已有配置与存储，不重复持有密钥。
- [ ] **S08 设置页混入大段报表（实测）。** Plan & quota 实际主要是阈值和 Open Usage；Estimated token cost 列出今日、7 天、模型与项目明细，辅助功能树将报表合成很长的一段文本。
  - 方案：额度页改用准确标题；费用页保留预算阈值、简短摘要和查看明细入口，复用 Usage 页面已有能力。先确认目标页支持对应明细，不先删除信息。
  - 验收：估算费用与真实账单仍明确区分；原报表信息都能到达；无重复计算或第二份用量状态。
- [ ] **S09 技术状态欠缺动作解释（实测）。** Agent CLIs 显示 `Sandbox: {"type":"danger-full-access"}` 原始 JSON；Diagnostics 显示 Codex App server Not installed，同时仍有 Rollout 信号。后者可能是两种来源的真实差异，未证明检测逻辑错误。
  - 方案：权限与沙盒用现有枚举的可读名称，未知值仍标未知并可查看原值；来源状态说明影响范围，区分可选未配置、等待信号和实际故障。每个修复按钮说明作用对象与修改范围。
  - 验收：读到 App server 不可用不会理解为全部 Codex 监控停止；不将未知降格成正常，不伪造安装或修复成功；未安装与不可连接若共用文案需核对现有状态来源。
- [ ] **S10 应用语言、阅读密度与键盘路径（实测缺口＋建议）。** 安装版 General 无应用语言入口，Voice 的 English/中文只控制语音与摘要；工作区已经新增应用语言设置，不能重复实现。长说明与高级字段的折叠应服务配置顺序。
  - 后续协调（2026-10-01）：已核对语言功能提交 `f61b1167`，仅涉及语言视图、General 入口和三条中文文案。来源会话 `01a0f6e9-43c9-7802-9919-c1abd228d7ad` 报告 Debug 构建及隔离 GUI 的 English→简体中文→English 两次重启实测通过，窗口标题、侧栏、系统菜单和偏好保留均符合预期；本会话未独立重跑该验证。来源证据位置：`.scratch/mac-language-run`、`.scratch/mac-language-build`、`/tmp/vibebuddy-language-build.log`，均为本机临时产物。安装版未替换，提交未推送。
  - 后续不再重做语言入口；只验收本工单改动后的受影响页面、布局和键盘路径。使用本会话独立的 bundle ID、端口、运行根目录及 DerivedData，避免与语言验收副本共用窗口。S10 因这些剩余检查继续保持未完成。
  - 方案：验收已有语言入口，明确它与语音语言的区别及重启生效范围；对上述改动页检查最小支持窗口的滚动、焦点、Tab 顺序和中文换行。保留已实测正常的快捷键 Cancel 行为。
  - 验收：语言切换不重置其他偏好；按钮和错误信息可读且可达；不靠增大窗口掩盖布局问题。搜索框、新导航框架和全设置迁移不在本轮范围。

## UX / DX / AX 取舍

| 决策 | UX | DX | AX 与代价 |
|---|---|---|---|
| 优先语义标签和明确文案 | 操作目的直接可见，VoiceOver 可读 | 复用现有 SwiftUI 控件，不建新框架 | 稳定 ID 和状态可被 Agent 操作；需逐项验证运行时 AX 树 |
| 普通偏好即时保存；密钥显式保存 | 常用设置少一步，密钥可取消 | 只给凭据增加草稿状态 | Agent 能区分草稿/已保存/已验证；密钥多一次点击，换取明确生效点 |
| 功能内给下一步，高级项折叠 | 新用户不用先学 model ID，老用户仍可编辑 | 保留现有 provider/model 绑定 | 禁用原因和下一步可读取；返回入口需记住来源功能 |
| 调整少量入口，复用现有报表与诊断 | 减少找错页，不丢信息 | 不新增用量/连接状态源 | 工单保留代码锚点和验收路径；同步维护页面名称引用 |
| 保留连接/通知契约 | 已有手机和通知继续按原规则工作 | 无迁移、无协议扩展 | 状态准确而非笼统“成功”；真机与系统权限流程单独验收 |

# SET-03：服务商密钥支持保存取消与失败重试

Status: ready-for-agent
Blocked by: None（可立即开始）
Parent: [SET-01](01-settings-ux-dx-ax.md)

## What to build

密钥在明确保存成功后才生效；用户可以取消编辑并保留旧配置。

## Acceptance criteria

- [ ] 输入是草稿；取消、切页、关闭窗口不覆盖旧密钥；清空输入不隐式移除凭据。
- [ ] 保存失败保留草稿与旧已保存值，可重试；移除为独立明确动作，存储 account 不变。
- [ ] 测试仅用已保存配置；保存改变后旧验证状态失效，保存不等于连接验证成功。
- [ ] 每个服务商的动作和状态可通过 AX 明确区分；用替身存储或隔离测试凭据保留保存/取消/失败的少量回归检查。

## Boundaries

保留既有未提交工作；不变更真实凭据、生产安装、连接协议或既有默认行为。每票包含适用构建、Computer Use 和回归验证，记录已验证与未验证状态。所有UI修改同时评估UX、DX、AX，优先复用现有组件，不引入设置框架。

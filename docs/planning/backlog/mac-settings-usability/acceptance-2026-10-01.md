2026-10-01。SET-02 至 SET-08 由七个独立会话实施、协调会话集成。实现子票已收尾；原始 SET-01 审计保持不变。此记录区分本地验证与尚未完成的生产验收。

| 范围 | 实现 | UX / DX / AX 取舍 |

## 已复现问题的重放检查

macOS 27.0.1 上，在 DisclosureGroup 容器设置 accessibilityLabel 后，Computer Use 展开语音高级设置和权限原值会触发 SwiftUI AX 递归，进程栈溢出。修复为明确的 label Text，并将标识附到标题，不覆盖容器语义。

重放：打开语音页 → 分别展开三项高级模型设置 → 读取 AX → 通话模型输入应仍为 `voiceModelID`；打开 Agent 接入 → 展开 Codex 上报原值 → 读取 AX，应出现审批和沙盒原始值，进程保持运行。两条路径均在修复后重放通过。

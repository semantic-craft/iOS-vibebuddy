# vibebuddy 1.3 — Watch quota at a glance

Candidate 1.3 (7) integrates the Watch quota work with the notification, connection and companion improvements prepared for 1.2. Installation and real-device acceptance are recorded separately; this candidate is not yet published.

- A circular Quota complication complements the existing rectangular Followed tasks complication. Choose Codex, Claude or both, with separate settings for each complication instance.
- Five display styles: remaining rings, number first, ten segments, dual windows and reset countdown. Select the weekly or short window where applicable.
- Quota displays remaining usage from the source. Missing values stay unknown; cached data and reset boundaries retain their evidence status instead of inventing a fresh allowance.
- Tap Quota to open its Watch detail without marking a followed task or completion as read.

The notification, approval, missed-wait tracking, source diagnostics, Mac window recovery and explicit paste controls from the 1.2 candidate are retained. Available provider data and system complication refresh scheduling determine what can be shown and when it updates.

Watch dictation, supplemental instructions and new-task creation remain outside this candidate. No project-operated notification relay is introduced. Mac distribution uses Developer ID signing and notarization; iPhone and Watch remain self-install companions. This is not an App Store submission.

Acceptance uses a frozen candidate and a continuous half-hour of actual use, with separate Watch face configuration and visual checks. Any relevant fix requires a new candidate and renewed acceptance.

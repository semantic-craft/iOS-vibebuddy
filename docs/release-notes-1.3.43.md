# VibeBuddy Mac 1.3.43

Codex Desktop 0.159.0-alpha.12.1 now has verified rollout compatibility. Agent setup distinguishes an unverified source version from a source that cannot be read, so compatibility information no longer looks like a connection failure. Other unverified alpha versions remain unverified.

This release also includes the previously prepared Grok Build monitoring improvements: connection status before the first task, configuration repair and retry guidance, and discovered projects shown separately from active tasks. Connection status is shared with VibeBuddy iPhone 1.3.34 and later.

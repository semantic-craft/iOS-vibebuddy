# VibeBuddy 1.3.33 — iOS

- MiniMax 朗读可独立选择语言，显示当前风格实际使用的音色和模型；密钥支持编辑、保存、取消和删除。
- 展示 Codex 任务目标、分页历史及后台终端；服务不可用时明确提示并回退到可用历史。
- 改善连接、观测和离线状态说明，以及中文和无障碍操作提示。
- 播放失败后可主动选择系统语音；通话和中断后保留暂停，避免意外重播。
- 减少朗读音频会话重复启停，修复接管失败后的释放及大字号下密钥编辑键盘问题。

摘要内容由 Mac 生成，朗读声音和密钥在 iPhone 设置。真实 MiniMax 四种风格及定向模拟器 E2E 已通过；真机耳听、耳机路由和 VoiceOver 共存仍待设备验收。

# 05: 增加隐私受控的生命周期事件日志

**What to build:** VibeBuddy 保存一个容量有上限的本地生命周期日志，用于重启恢复、解释状态来源和诊断漏报；日志只记录规范化状态变化与必要的来源元数据，默认不保留完整 prompt、推理、消息正文或工具输出。

**Blocked by:** 02: 显示观察来源与兼容性健康状态.

**Status:** ready-for-agent

- [ ] 每条记录包含会话身份、代理、规范化事件、观察来源、时间和归约结果，但默认不写入完整用户/助手内容或工具输入输出。
- [ ] 日志按明确的容量或保留期自动轮转，损坏、升级中断或磁盘不可写时监控继续 fail-open 运行。
- [ ] daemon 重启后仅恢复仍有意义的活动/等待状态，不重放旧完成通知，也不让已结束会话重新出现。
- [ ] 设置或诊断界面能查看经过脱敏的近期时间线并清除日志；仅用少量快速回归测试保护轮转、隐私字段和恢复主路径，并以实际 daemon 重启、损坏/不可写模拟完成端到端验收。

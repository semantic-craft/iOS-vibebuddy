七、验收规则

  1. TDD：先写能证明归约语义的少量聚焦测试，再实现；不要以扩大测试数量代替真实链路。
  2. 每个 ticket 至少：聚焦测试、相关完整套件、Mac/iOS build、真实 agent/通知 E2E、独立代码审查。
  3. 逐层记录：实现完成 ≠ commit ≠ push ≠ merge ≠ 已安装 App 验收 ≠ release。
  4. 更新对应本地 markdown 工单的 checklist、Status 与 Implementation notes；只在全部满足后设为 ready-for-human。
  5. 发现输入信号不足时降级为 unknown/degraded，并把证据缺口写回工单；不得伪造 running/done/delivered。
